CLASSFOCUS v4 + POSTGRESQL

UBUNTU / LINUX
1. Abre una terminal en la carpeta ClassFocus.
2. Ejecuta:

   chmod +x start.sh
   ./start.sh

3. Abre: http://localhost:5173

Si tienes Docker Compose, PostgreSQL se levantará con:
   docker compose up -d postgres

API PostgreSQL:
   http://localhost:8788/api/health
