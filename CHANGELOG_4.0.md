# ClassFocus 4.0

## PostgreSQL
- Se agregó PostgreSQL como base de datos persistente.
- Nueva API Express en puerto 8788.
- Persistencia para usuarios, materias, asignaciones, exámenes, incidencias y atención.
- Inicio automático de tablas y datos demo.
- Soporte Docker Compose y PostgreSQL local.
- Indicador visual de estado PostgreSQL / modo local.
- Caché local de respaldo para que la demo siga funcionando si la base está apagada.

## Se mantiene
- Super Admin.
- Materias y asignaciones.
- Evaluaciones con duración.
- Google Classroom.
- MediaPipe.
- Cámaras WebRTC.
- Tema claro/oscuro.
- Identidad USPG.
